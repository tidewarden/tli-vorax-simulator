# Vorax Simulator and Solver

Tools for the Surgical Preparation minigame in Torchlight Infinite (SS11, Vorax):

- **Simulator:** practice runs and a sandbox, with the Optimal Play guide.
- **Solver:** advice for your real game. It reads your screen and shows the best move. It only reads: it never clicks or types for you.

**Use them:** https://voraxlab.pages.dev/tli-vorax-simulator/

**Vorax Overlay**, the Solver as a Windows app with its advice over the game: download **Vorax-Overlay-Setup.exe** from the [latest release](https://github.com/tidewarden/tli-vorax-simulator/releases/latest). Installed copies update themselves.

**Something wrong?** [Report an issue](https://github.com/tidewarden/tli-vorax-simulator/issues/new/choose).

This repo holds the app's releases and the issue reports. The code is no longer published here.
